# Superpowers artifacts

Store **design specs** and **implementation plans** here when using the Superpowers workflow (same convention as BrgyCloud/comshop).

```text
docs/superpowers/
  specs/    YYYY-MM-DD-<topic>-design.md
  plans/    YYYY-MM-DD-<topic>.md
```

Ephemeral SDD task output belongs in `.superpowers/sdd/` (gitignored).

Follow `.cursor/rules/superpowers-workflow.mdc` and root `AGENTS.md`.
